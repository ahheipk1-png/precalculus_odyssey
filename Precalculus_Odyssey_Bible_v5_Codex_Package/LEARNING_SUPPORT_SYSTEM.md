# Learning Support System

Every phase must teach as well as assess.

## Hint Sequence

1. Gentle Nudge
2. Concept Reminder
3. Focus Hint
4. Guided Step
5. Nearly Complete
6. Full Solution

## Tutorial

Target duration: 2–5 minutes.

Required:

- learning goal
- why it matters
- prerequisite review
- core concept
- worked example
- common mistakes
- guided practice
- independent practice
- mastery check

## Adaptive Recommendation

Recommend help when repeated errors, repeated hints, or prerequisite gaps are detected.
