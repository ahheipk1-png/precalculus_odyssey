# Project Principles

These principles are the non-negotiable constitution of the Odyssey educational system.

1. Learning is more important than testing.
2. Understanding is more important than memorization.
3. Question variety is more important than question count.
4. Changing only numbers or names does not create a new template.
5. Tutorials must teach concepts, not only procedures.
6. The AI tutor should guide before telling.
7. Hints must become gradually more explicit.
8. Every player should be able to learn a topic inside the game.
9. Difficulty should increase through reasoning before arithmetic complexity.
10. Every phase must support adaptive review.
11. Every concept must declare prerequisites and follow-up concepts.
12. Every generated question must be mathematically valid and unambiguous.
13. Every distractor must reflect a plausible misconception.
14. Every completed phase must be reusable across future Odyssey games.
15. Quality is more important than speed.
16. Completed work must be resumable and auditable.
17. No phase is complete without Question, Hint, Tutorial, and Socratic Dialogue Bibles.
18. Equation Battle must remain a major supported question family where mathematically appropriate.
19. The game should never force the player to leave the game to learn the topic.
20. The system should treat player mistakes as evidence about missing knowledge, not merely failure.
