# Phase 059 - Final boss challenges

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Final boss challenges
- Subtopic: Capstone synthesis across the full Precalculus Odyssey pathway
- Prerequisites: all previous Precalculus Odyssey phases
- Related phases: Phase 058 review; Phase 060 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of final boss challenges tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving final boss challenges questions.
3. Solve tasks involving linear modeling boss.
4. Solve tasks involving system modeling boss.
5. Solve tasks involving domain boss.
6. Solve tasks involving composition equation boss.
7. Solve tasks involving projectile quadratic boss.
8. Solve tasks involving polynomial factor boss.
9. Solve tasks involving rational expression boss.
10. Solve tasks involving exponential-logarithmic boss.

## Prerequisite Review
- Read the full prompt and identify the topic families involved before solving.
- List restrictions and units before finalizing an answer.
- Choose exact, decimal, graphical, or contextual form based on the question.
- Check solutions in the original relationship when squaring, logging, or simplifying rational expressions.
- Explain the final result in one sentence so the answer has meaning.

## Core Concepts
- A final boss problem combines skills but still breaks into legal smaller moves.
- Representation changes are tools: equations, graphs, vectors, and complex numbers can describe the same structure.
- Restrictions protect the solution from extraneous answers and impossible inputs.
- Modeling problems require a numeric result and an interpretation in context.
- Mastery means selecting methods flexibly and checking the result against the original prompt.

## Common Misconceptions
- Trying to apply one memorized procedure to every part of a multi-stage task.
- Forgetting that a simplified rational expression still carries original restrictions.
- Keeping extraneous roots after squaring an equation.
- Using a graph feature without connecting it to the equation that created it.
- Reporting intermediate values as final answers without context.

## Core Concept
- A final boss problem combines skills but still breaks into legal smaller moves.
- Representation changes are tools: equations, graphs, vectors, and complex numbers can describe the same structure.
- Restrictions protect the solution from extraneous answers and impossible inputs.
- Modeling problems require a numeric result and an interpretation in context.
- Mastery means selecting methods flexibly and checking the result against the original prompt.

## Worked Example
- A game pass costs 12 dollars plus 4 dollars per quest. If the total cost is 36 dollars, how many quests were purchased? Answer: 6 quests. Reason: Set up 12 + 4q = 36. Subtract 12 to get 4q = 24, then divide by 4 to get q = 6.
- A shop sold 7 items total. Apples cost 2 dollars each, berries cost 3 dollars each, and the total was 19 dollars. How many apples and berries were sold? Answer: 2 apples and 5 berries. Reason: Let a be apples and b be berries. The system is a + b = 7 and 2a + 3b = 19. From a = 7 - b, substitute to get 2(7 - b) + 3b = 19, so b = 5 and a = 2.
- Find the domain of h(x) = sqrt(12 - 3x)/(x + 1). Answer: (-infinity, -1) union (-1, 4]. Reason: The square root requires 12 - 3x >= 0, so x <= 4. The denominator requires x != -1. Combining these gives (-infinity, -1) union (-1, 4].
- Let f(x) = 3x - 5 and g(x) = x^2 + 1. Solve f(g(x)) = 22. Answer: x = 2sqrt(2) or x = -2sqrt(2). Reason: First compose: f(g(x)) = 3(x^2 + 1) - 5 = 3x^2 - 2. Set 3x^2 - 2 = 22, so 3x^2 = 24 and x^2 = 8. Thus x = 2sqrt(2) or x = -2sqrt(2).

## Common Mistakes

- Keeping extraneous roots after squaring an equation.

- Reporting intermediate values as final answers without context.
