9. Solve tasks involving build a model from two consecutive values.
10. Solve tasks involving doubling model.

## Prerequisite Review
- A percent increase of r becomes a multiplier of 1 + r.
- Repeated multiplication creates exponential change.
- Function notation such as f(3) means evaluate when the input is 3.
- Powers count repeated factors, not repeated addition.
- Tables with a constant ratio suggest exponential behavior.

## Core Concepts
- An exponential growth model has the form A = a b^t with a > 0 and b > 1.
- The initial value is the output when t = 0.
- The growth factor b is the multiplier for each equal time step.
- The percent growth rate is b - 1, written as a percent.
- Doubling models use a growth factor of 2 for each doubling interval.
- Continuous growth uses A = P e^(rt), where r is the continuous growth rate.

## Common Misconceptions
- Adding the percent rate each period instead of multiplying by the growth factor.
- Using 12 for a 12 percent increase instead of 1.12.
- Mistaking the initial value for the growth factor.
- Assuming every increasing table is exponential.
- Rounding too early in a multi-step model.

# Part III - Tutorial Bible

## Learning Goal
Master exponential growth by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A percent increase of r becomes a multiplier of 1 + r.
- Can the player explain this prerequisite? Repeated multiplication creates exponential change.
- Can the player explain this prerequisite? Function notation such as f(3) means evaluate when the input is 3.
- Can the player explain this prerequisite? Powers count repeated factors, not repeated addition.

## Core Concept
- An exponential growth model has the form A = a b^t with a > 0 and b > 1.
- The initial value is the output when t = 0.
- The growth factor b is the multiplier for each equal time step.
- The percent growth rate is b - 1, written as a percent.
- Doubling models use a growth factor of 2 for each doubling interval.
- Continuous growth uses A = P e^(rt), where r is the continuous growth rate.

## Worked Example
- If f(t) = 3(2^t), find f(4). Answer: 48 Reason: Substitute t = 4: f(4) = 3(2^4) = 3(16) = 48.
- For A(t) = 80(1.25^t), name the initial value and growth factor. Answer: Initial value 80; growth factor 1.25 Reason: When t = 0, 1.25^0 = 1, so the starting amount is 80. The base 1.25 is the multiplier each period.
- What growth factor represents a 7 percent increase each year? Answer: 1.07 Reason: A 7 percent increase means keep 100 percent and add 7 percent, so the multiplier is 1 + 0.07 = 1.07.
- A town has 5000 people and grows by 4 percent per year. Write a model for the population after t years. Answer: P(t) = 5000(1.04^t) Reason: The initial value is 5000. A 4 percent increase gives growth factor 1.04, so the model is P(t) = 5000(1.04^t).

## Common Mistakes
- Adding the percent rate each period instead of multiplying by the growth factor.
- Using 12 for a 12 percent increase instead of 1.12.
- Mistaking the initial value for the growth factor.
- Assuming every increasing table is exponential.
- Rounding too early in a multi-step model.
