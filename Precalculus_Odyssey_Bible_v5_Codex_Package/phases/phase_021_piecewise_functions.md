# Phase 021 - Piecewise functions

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Piecewise functions
- Subtopic: Evaluating, graphing, interpreting, and building piecewise-defined functions
- Prerequisites: function notation, inequalities, graph reading, domain intervals, linear equations
- Related phases: Phase 020 review; Phase 022 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of piecewise functions tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving piecewise functions questions.
3. Solve tasks involving basic branch selection.
4. Solve tasks involving endpoint inclusion.
5. Solve tasks involving negative input branch.
6. Solve tasks involving evaluate at zero.
7. Solve tasks involving multiple intervals.
8. Solve tasks involving right boundary.
9. Solve tasks involving table from piecewise rule.
10. Solve tasks involving graph endpoint choice.

## Prerequisite Review
- A piecewise function uses different formulas on different parts of the domain.
- The input value decides which branch applies.
- Closed endpoints are included; open endpoints are not included.
- Function notation still means replace the input after choosing the correct branch.
- A graph can jump, connect, or have holes at piecewise boundaries.

## Core Concepts
- Choose the branch by checking the input against the condition first.
- Only evaluate the formula from the branch that contains the input.
- At a boundary, endpoint symbols decide which formula gives the function value.
- Piecewise graphs are built one interval at a time.
- Continuity at a join requires matching output values from both sides.
- Context piecewise models often represent tiered prices, rates, or rules.

## Common Misconceptions
- Evaluating every branch and choosing the nicest answer.
- Ignoring whether an endpoint uses < or <=.
- Using the y-value to choose a branch instead of the x-value.
- Assuming a jump graph cannot still be a function.
- Forgetting to restrict each graph segment to its interval.

## Common Mistakes
- Evaluating every branch and choosing the nicest answer.
- Ignoring whether an endpoint uses < or <=.
- Using the y-value to choose a branch instead of the x-value.
- Assuming a jump graph cannot still be a function.
- Forgetting to restrict each graph segment to its interval.
