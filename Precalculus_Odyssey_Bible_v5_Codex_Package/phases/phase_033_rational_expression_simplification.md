# Phase 033 - Rational expression simplification

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Rational expression simplification
- Subtopic: Simplifying rational expressions by factoring and cancelling common factors
- Prerequisites: factoring, polynomial expressions, domain restrictions, fraction simplification
- Related phases: Phase 032 review; Phase 034 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of rational expression simplification tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving rational expression simplification questions.
3. Solve tasks involving cancel monomial factor.
4. Solve tasks involving cancel binomial factor.
5. Solve tasks involving factor trinomial.
6. Solve tasks involving cancel denominator factor.
7. Solve tasks involving gcf numerator.
8. Solve tasks involving gcf both.
9. Solve tasks involving difference of squares both.
10. Solve tasks involving opposite binomials.

## Prerequisite Review
- A rational expression is a ratio of polynomials.
- Values that make the original denominator zero are excluded.
- A common factor can create a hole after cancellation.
- A non-cancelled denominator factor creates a vertical asymptote.
- Horizontal asymptotes are predicted from degrees and leading coefficients.

## Core Concepts
- Factor numerator and denominator before cancelling.
- Only common factors may be cancelled.
- Restrictions come from the original denominator.
- A simplified expression may hide excluded values.
- Signs can be factored out to reveal common binomials.
- Simplification should be checked by multiplication.

## Common Misconceptions
- Cancelling terms that are not common factors.
- Forgetting restrictions from the original denominator.
- Calling every excluded value an asymptote.
- Ignoring holes after simplifying.
- Using y-values instead of x-values for denominator restrictions.

# Part III - Tutorial Bible

## Learning Goal
Master rational expression simplification by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A rational expression is a ratio of polynomials.
- Can the player explain this prerequisite? Values that make the original denominator zero are excluded.
- Can the player explain this prerequisite? A common factor can create a hole after cancellation.
- Can the player explain this prerequisite? A non-cancelled denominator factor creates a vertical asymptote.

## Core Concept
- Factor numerator and denominator before cancelling.
- Only common factors may be cancelled.
- Restrictions come from the original denominator.
- A simplified expression may hide excluded values.
- Signs can be factored out to reveal common binomials.
- Simplification should be checked by multiplication.

## Worked Example
- Simplify 6x^2/(3x). Answer: 2x, x != 0 Reason: Cancel common factor 3x; x=0 is excluded from the original denominator.
- Simplify (x^2-9)/(x-3). Answer: x+3, x != 3 Reason: Factor numerator as (x-3)(x+3), then cancel x-3.
- Simplify (x^2+5x+6)/(x+2). Answer: x+3, x != -2 Reason: Factor numerator as (x+2)(x+3).
- Simplify (x^2-4)/(x^2+x-6). Answer: (x+2)/(x+3), x != 2,-3 Reason: Factor to (x-2)(x+2)/((x+3)(x-2)) and cancel x-2.

## Common Mistakes
- Cancelling terms that are not common factors.
- Forgetting restrictions from the original denominator.
- Calling every excluded value an asymptote.
- Ignoring holes after simplifying.
- Using y-values instead of x-values for denominator restrictions.
