# Phase 047 - Amplitude and period

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Amplitude and period
- Subtopic: Vertical stretch and horizontal cycle length in trigonometric graphs
- Prerequisites: Trigonometric graphs, sine and cosine key points, tangent asymptotes, absolute value, and function transformations
- Related phases: Phase 046 review; Phase 048 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of amplitude and period tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving amplitude and period questions.
3. Solve tasks involving amplitude of a sine graph.
4. Solve tasks involving amplitude with reflection.
5. Solve tasks involving period of compressed sine.
6. Solve tasks involving period of stretched cosine.
7. Solve tasks involving amplitude and period together.
8. Solve tasks involving reflection with period.
9. Solve tasks involving finding b from period.
10. Solve tasks involving finding amplitude from range.

## Prerequisite Review
- Identify the maximum, minimum, and midline of a graph.
- Recall that sine and cosine have base period 2pi and tangent has base period pi.
- Use absolute value to interpret amplitude as a distance.
- Recognize that horizontal scaling changes the period by a reciprocal factor.

## Core Concepts
- For y = A sin(Bx) or y = A cos(Bx), the amplitude is |A|.
- For y = A sin(Bx) or y = A cos(Bx), the period is 2pi/|B|.
- For y = A tan(Bx), the period is pi/|B|.
- A negative leading coefficient reflects the graph but does not make amplitude negative.
- The range of an unshifted sine or cosine graph with amplitude A is [-|A|, |A|].

## Common Misconceptions
- Reporting a negative amplitude when A is negative.
- Multiplying by B instead of dividing the base period by |B|.
- Using 2pi/|B| as the period for tangent.
- Confusing amplitude with total height from minimum to maximum.
- Changing the period when only the amplitude changes.

- Can the player explain this prerequisite? Recall that sine and cosine have base period 2pi and tangent has base period pi.
- Can the player explain this prerequisite? Use absolute value to interpret amplitude as a distance.
- Can the player explain this prerequisite? Recognize that horizontal scaling changes the period by a reciprocal factor.

## Core Concept
- For y = A sin(Bx) or y = A cos(Bx), the amplitude is |A|.
- For y = A sin(Bx) or y = A cos(Bx), the period is 2pi/|B|.
- For y = A tan(Bx), the period is pi/|B|.
- A negative leading coefficient reflects the graph but does not make amplitude negative.
- The range of an unshifted sine or cosine graph with amplitude A is [-|A|, |A|].

## Worked Example
- Find the amplitude of y = 3sin x. Answer: 3 Reason: For y = A sin x, amplitude is |A|. Here |3| = 3.
- Find the amplitude of y = -4cos x. Answer: 4 Reason: Amplitude is a distance, so it is never negative. Since |-4| = 4, the amplitude is 4.
- Find the period of y = sin(2x). Answer: pi Reason: For sine, period = 2pi/|B|. Here B = 2, so the period is 2pi/2 = pi.
- Find the period of y = cos(x/2). Answer: 4pi Reason: The coefficient of x is B = 1/2. The period is 2pi/(1/2) = 4pi.

## Common Mistakes
- Reporting a negative amplitude when A is negative.
- Multiplying by B instead of dividing the base period by |B|.
- Using 2pi/|B| as the period for tangent.
- Confusing amplitude with total height from minimum to maximum.
- Changing the period when only the amplitude changes.

## Independent Practice
- Comparing amplitude and period changes: Compare y = 2sin x and y = sin(2x). Which changes amplitude, and which changes period? Expected answer: y = 2sin x changes amplitude; y = sin(2x) changes period..
- Building an equation from amplitude and period: Write one sine equation with amplitude 3, period pi, and no shifts. Expected answer: y = 3sin(2x).
- Range from amplitude: Find the range of y = -6cos(2x). Expected answer: [-6, 6].
- Cycles on an interval: How many full cycles does y = sin(5x) complete on [0, 2pi]? Expected answer: 5 full cycles.
- Period with a real-world scale: Find the amplitude and period of y = 4sin((pi/6)x). Expected answer: Amplitude 4; period 12.
- Finding B from cycle count: A graph y = A sin(Bx) completes 2 full cycles on [0, 2pi], with B > 0. Find B. Expected answer: B = 2.
