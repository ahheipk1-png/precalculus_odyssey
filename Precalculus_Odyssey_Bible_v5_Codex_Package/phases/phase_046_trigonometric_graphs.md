# Phase 046 - Trigonometric graphs

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Trigonometric graphs
- Subtopic: Key features of sine, cosine, and tangent graphs
- Prerequisites: Unit circle values, exact trigonometric values, coordinate graphs, intercepts, and intervals
- Related phases: Phase 045 review; Phase 047 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of trigonometric graphs tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving trigonometric graphs questions.
3. Solve tasks involving maximum of the sine graph.
4. Solve tasks involving zeros of the cosine graph.
5. Solve tasks involving vertical asymptotes of tangent.
6. Solve tasks involving key value on the sine graph.
7. Solve tasks involving identifying cosine from graph behavior.
8. Solve tasks involving intercepts of the sine graph.
9. Solve tasks involving increasing intervals for sine.
10. Solve tasks involving range from a shifted sine graph.

## Prerequisite Review
- Connect sine and cosine values to unit-circle coordinates.
- Plot points in the coordinate plane using radians on the x-axis.
- Identify x-intercepts, maximum values, minimum values, and increasing intervals from a graph.
- Recognize that tangent has vertical asymptotes where cosine is zero.

## Core Concepts
- The basic sine graph starts at (0, 0), rises to 1 at pi/2, returns to 0 at pi, reaches -1 at 3pi/2, and returns to 0 at 2pi.
- The basic cosine graph starts at (0, 1), reaches 0 at pi/2, reaches -1 at pi, returns to 0 at 3pi/2, and returns to 1 at 2pi.
- The tangent graph has period pi and vertical asymptotes at pi/2 + kpi.
- Graph features can be read from key points, intercepts, symmetry, and asymptotes.
- A graph can be identified by its starting value and first direction of motion.

## Common Misconceptions
- Thinking sine and cosine have the same starting point.
- Drawing tangent with a highest and lowest value like sine or cosine.
- Forgetting the vertical asymptotes of tangent.
- Counting endpoints incorrectly on interval questions.
- Reading radians as if they were degrees on the horizontal axis.

## Core Concept
- The basic sine graph starts at (0, 0), rises to 1 at pi/2, returns to 0 at pi, reaches -1 at 3pi/2, and returns to 0 at 2pi.
- The basic cosine graph starts at (0, 1), reaches 0 at pi/2, reaches -1 at pi, returns to 0 at 3pi/2, and returns to 1 at 2pi.
- The tangent graph has period pi and vertical asymptotes at pi/2 + kpi.
- Graph features can be read from key points, intercepts, symmetry, and asymptotes.
- A graph can be identified by its starting value and first direction of motion.

## Worked Example
- On the graph of y = sin x over [0, 2pi], what is the maximum value and where does it first occur? Answer: The maximum value is 1 at x = pi/2. Reason: The basic sine graph reaches its highest point at the top of the unit circle. On [0, 2pi], that first happens at x = pi/2 with y = 1.
- Find the x-intercepts of y = cos x on [0, 2pi]. Answer: x = pi/2 and x = 3pi/2 Reason: Cosine is the x-coordinate on the unit circle. It equals 0 at pi/2 and 3pi/2, so those are the x-intercepts.
- Find the vertical asymptotes of y = tan x on (-pi, pi). Answer: x = -pi/2 and x = pi/2 Reason: tan x = sin x/cos x, so tangent has vertical asymptotes where cos x = 0. In (-pi, pi), that occurs at -pi/2 and pi/2.
- What is the value of y = sin x at x = 3pi/2? Answer: -1 Reason: At 3pi/2 on the unit circle, the y-coordinate is -1. Therefore the sine graph has value -1 there.

## Common Mistakes
- Thinking sine and cosine have the same starting point.
- Drawing tangent with a highest and lowest value like sine or cosine.
- Forgetting the vertical asymptotes of tangent.
- Counting endpoints incorrectly on interval questions.
- Reading radians as if they were degrees on the horizontal axis.
