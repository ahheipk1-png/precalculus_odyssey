# Phase 053 - Sequences

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Sequences
- Subtopic: Arithmetic, geometric, recursive, and explicit sequence rules
- Prerequisites: Function notation, linear patterns, exponential patterns, substitution, and solving simple equations
- Related phases: Phase 052 review; Phase 054 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of sequences tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving sequences questions.
3. Solve tasks involving continuing an arithmetic sequence.
4. Solve tasks involving common difference.
5. Solve tasks involving explicit arithmetic rule.
6. Solve tasks involving finding an arithmetic term.
7. Solve tasks involving finding an index in an arithmetic sequence.
8. Solve tasks involving continuing a geometric sequence.
9. Solve tasks involving common ratio.
10. Solve tasks involving explicit geometric rule.

## Prerequisite Review
- Evaluate formulas by substituting a value for n.
- Recognize constant differences as linear patterns.
- Recognize constant ratios as exponential patterns.
- Solve simple equations involving n.

## Core Concepts
- A sequence is an ordered list of terms, often written a_1, a_2, a_3, and so on.
- An arithmetic sequence has a constant difference d and explicit form a_n = a_1 + d(n - 1).
- A geometric sequence has a constant ratio r and explicit form a_n = a_1 r^(n - 1).
- A recursive rule defines a term using earlier term values.
- The index n tells the position of a term, not always the term value itself.

## Common Misconceptions
- Using n instead of n - 1 in explicit sequence formulas.
- Confusing common difference with common ratio.
- Calling any increasing sequence arithmetic.
- Starting a recursive rule with the wrong first term.
- Assuming geometric ratios must be positive.

# Part III - Tutorial Bible

## Learning Goal
Master sequences by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check

- Can the player explain this prerequisite? Recognize constant differences as linear patterns.
- Can the player explain this prerequisite? Recognize constant ratios as exponential patterns.
- Can the player explain this prerequisite? Solve simple equations involving n.

## Core Concept
- A sequence is an ordered list of terms, often written a_1, a_2, a_3, and so on.
- An arithmetic sequence has a constant difference d and explicit form a_n = a_1 + d(n - 1).
- A geometric sequence has a constant ratio r and explicit form a_n = a_1 r^(n - 1).
- A recursive rule defines a term using earlier term values.
- The index n tells the position of a term, not always the term value itself.

## Worked Example
- Find the next two terms of 5, 8, 11, ... Answer: 14, 17 Reason: The common difference is 3. Add 3 to 11 to get 14, then add 3 again to get 17.
- Find the common difference of 20, 15, 10, 5, ... Answer: -5 Reason: Each term decreases by 5. For example, 15 - 20 = -5 and 10 - 15 = -5.
- Write an explicit rule for the arithmetic sequence with a_1 = 7 and d = 4. Answer: a_n = 7 + 4(n - 1), or a_n = 4n + 3 Reason: Use a_n = a_1 + d(n - 1). Substituting a_1 = 7 and d = 4 gives a_n = 7 + 4(n - 1), which simplifies to 4n + 3.
- Find a_12 for the arithmetic sequence with a_1 = 3 and d = 5. Answer: 58 Reason: Use a_n = a_1 + d(n - 1). Then a_12 = 3 + 5(12 - 1) = 3 + 55 = 58.

## Common Mistakes
- Using n instead of n - 1 in explicit sequence formulas.
- Confusing common difference with common ratio.
- Calling any increasing sequence arithmetic.
- Starting a recursive rule with the wrong first term.
- Assuming geometric ratios must be positive.
