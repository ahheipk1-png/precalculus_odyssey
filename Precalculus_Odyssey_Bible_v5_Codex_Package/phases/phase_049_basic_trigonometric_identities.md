# Phase 049 - Basic trigonometric identities

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Basic trigonometric identities
- Subtopic: Reciprocal, quotient, and Pythagorean identities for simplification and verification
- Prerequisites: Exact trigonometric values, algebraic simplification, fractions, quadrants, and equation reasoning
- Related phases: Phase 048 review; Phase 050 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of basic trigonometric identities tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving basic trigonometric identities questions.
3. Solve tasks involving quotient identity for tangent.
4. Solve tasks involving finding tangent from sine and cosine.
5. Solve tasks involving reciprocal identity for cosecant.
6. Solve tasks involving main pythagorean identity.
7. Solve tasks involving tangent pythagorean identity.
8. Solve tasks involving difference form of a pythagorean identity.
9. Solve tasks involving reciprocal product.
10. Solve tasks involving simplifying with tangent quotient.

## Prerequisite Review
- Use sine, cosine, and tangent values from the unit circle.
- Simplify fractions and factor expressions carefully.
- Recall that tangent is sine divided by cosine.
- Use quadrant signs when extracting a square root from a squared trig value.

## Core Concepts
- Reciprocal identities include csc x = 1/sin x, sec x = 1/cos x, and cot x = 1/tan x.
- Quotient identities include tan x = sin x/cos x and cot x = cos x/sin x.
- The main Pythagorean identity is sin^2 x + cos^2 x = 1.
- Related Pythagorean identities are 1 + tan^2 x = sec^2 x and 1 + cot^2 x = csc^2 x.
- Identity work must respect where expressions are defined.

## Common Misconceptions
- Canceling terms across addition, such as reducing (sin x + 1)/sin x to 2.
- Treating csc x as sin^-1 x instead of 1/sin x.
- Forgetting domain restrictions when dividing by sine or cosine.
- Taking a positive square root in every quadrant.
- Trying to prove an identity by testing only one angle.

## Core Concept
- Reciprocal identities include csc x = 1/sin x, sec x = 1/cos x, and cot x = 1/tan x.
- Quotient identities include tan x = sin x/cos x and cot x = cos x/sin x.
- The main Pythagorean identity is sin^2 x + cos^2 x = 1.
- Related Pythagorean identities are 1 + tan^2 x = sec^2 x and 1 + cot^2 x = csc^2 x.
- Identity work must respect where expressions are defined.

## Worked Example
- Rewrite tan x using sine and cosine. Answer: tan x = sin x/cos x Reason: The quotient identity defines tangent as the ratio of sine to cosine when cos x is not zero.
- If sin x = 3/5 and cos x = 4/5, find tan x. Answer: 3/4 Reason: Use tan x = sin x/cos x. Then tan x = (3/5)/(4/5) = 3/4.
- If sin x = -2/3, find csc x. Answer: -3/2 Reason: Cosecant is the reciprocal of sine, so csc x = 1/(-2/3) = -3/2.
- Simplify sin^2 x + cos^2 x. Answer: 1 Reason: The Pythagorean identity states that sin^2 x + cos^2 x = 1 for every angle x.

## Common Mistakes
- Canceling terms across addition, such as reducing (sin x + 1)/sin x to 2.
- Treating csc x as sin^-1 x instead of 1/sin x.
- Forgetting domain restrictions when dividing by sine or cosine.
- Taking a positive square root in every quadrant.
- Trying to prove an identity by testing only one angle.
