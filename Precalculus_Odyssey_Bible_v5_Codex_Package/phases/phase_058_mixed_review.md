# Phase 058 - Mixed review

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Mixed review
- Subtopic: Integrated review across algebra, functions, trigonometry, sequences, conics, vectors, and complex numbers
- Prerequisites: linear equations, functions, quadratics, rational expressions, exponentials, logarithms, trigonometry, sequences, conics, vectors, complex numbers
- Related phases: Phase 057 review; Phase 059 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of mixed review tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving mixed review questions.
3. Solve tasks involving solving a linear equation.
4. Solve tasks involving solving an absolute value inequality.
5. Solve tasks involving solving a system.
6. Solve tasks involving evaluating a composition.
7. Solve tasks involving finding domain from a formula.
8. Solve tasks involving finding an inverse function.
9. Solve tasks involving factoring a quadratic.
10. Solve tasks involving solving a quadratic with complex roots.

## Prerequisite Review
- Name the topic family before choosing a method.
- Check restrictions before and after solving equations.
- Use exact values when the question is built from exact trig or radical data.
- Translate between symbolic, graphical, numerical, and verbal representations.
- Write final answers in the form requested by the problem.

## Core Concepts
- Mixed review rewards method selection before computation.
- A correct answer includes restrictions, units, or intervals when the context needs them.
- Earlier algebra skills support later function, trigonometric, and modeling tasks.
- Graph features often come from rewriting an equation into a more revealing form.
- Boss readiness means explaining why a method applies, not only getting a number.

## Common Misconceptions
- Solving every problem with the most recent topic instead of the visible structure.
- Forgetting domain restrictions after algebraic simplification.
- Using decimal approximations when exact values are cleaner and requested.
- Stopping after a setup without answering the question asked.
- Treating a representation change as a different problem instead of the same relationship.

## Worked Example
- Solve 3(2x - 1) = 15. Answer: x = 3. Reason: Distribute to get 6x - 3 = 15. Add 3 to both sides: 6x = 18. Divide by 6 to get x = 3.
- Solve |x - 4| < 7. Answer: -3 < x < 11. Reason: The inequality |x - 4| < 7 means -7 < x - 4 < 7. Add 4 to all three parts to get -3 < x < 11.
- Solve the system y = 2x + 1 and x + y = 10. Answer: (3, 7). Reason: Substitute y = 2x + 1 into x + y = 10 to get x + 2x + 1 = 10. Then 3x = 9, so x = 3 and y = 7.
- If f(x) = x^2 + 1 and g(x) = 3x - 2, find f(g(2)). Answer: 17. Reason: First find g(2) = 3(2) - 2 = 4. Then f(4) = 4^2 + 1 = 17.
