# Phase 050 - Trigonometric equations

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Trigonometric equations
- Subtopic: Solving trigonometric equations on restricted intervals
- Prerequisites: Exact trigonometric values, unit circle, basic trigonometric identities, factoring, and interval notation
- Related phases: Phase 049 review; Phase 051 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of trigonometric equations tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving trigonometric equations questions.
3. Solve tasks involving basic sine equation.
4. Solve tasks involving basic cosine equation.
5. Solve tasks involving basic tangent equation.
6. Solve tasks involving isolating sine.
7. Solve tasks involving isolating cosine.
8. Solve tasks involving equation with a doubled angle.
9. Solve tasks involving squared sine equation.
10. Solve tasks involving squared cosine equation.

## Prerequisite Review
- Use unit-circle angles for common sine, cosine, and tangent values.
- Factor simple algebraic expressions before solving.
- Check every solution against the required interval.
- Avoid dividing by a trig expression when it may equal zero.

## Core Concepts
- Trigonometric equations often have more than one solution on a finite interval.
- Solve by isolating the trig function, using identities, factoring, and then reading angles from the unit circle.
- Squaring or dividing can create lost or extra solutions, so checking matters.
- For equations involving 2x or x - C, solve the inner angle first and then translate back to x.
- The interval determines which coterminal solutions are included.

## Common Misconceptions
- Writing only the reference angle as the answer.
- Forgetting a second quadrant or third quadrant solution with the same trig value.
- Including 2pi when the interval is [0, 2pi).
- Dividing by sin x or cos x and losing zero solutions.
- Using degree answers when the problem is in radians.

# Part III - Tutorial Bible

## Learning Goal
Master trigonometric equations by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? Use unit-circle angles for common sine, cosine, and tangent values.
- Can the player explain this prerequisite? Factor simple algebraic expressions before solving.
- Can the player explain this prerequisite? Check every solution against the required interval.
- Can the player explain this prerequisite? Avoid dividing by a trig expression when it may equal zero.

## Core Concept
- Trigonometric equations often have more than one solution on a finite interval.
- Solve by isolating the trig function, using identities, factoring, and then reading angles from the unit circle.
- Squaring or dividing can create lost or extra solutions, so checking matters.
- For equations involving 2x or x - C, solve the inner angle first and then translate back to x.
- The interval determines which coterminal solutions are included.

## Worked Example
- Solve sin x = 1/2 on [0, 2pi). Answer: x = pi/6, 5pi/6 Reason: Sine is positive in quadrants I and II. The reference angle for 1/2 is pi/6, so the solutions are pi/6 and 5pi/6.
- Solve cos x = -1/2 on [0, 2pi). Answer: x = 2pi/3, 4pi/3 Reason: Cosine is negative in quadrants II and III. The reference angle is pi/3, giving 2pi/3 and 4pi/3.
- Solve tan x = 1 on [0, 2pi). Answer: x = pi/4, 5pi/4 Reason: Tangent is positive in quadrants I and III. The reference angle is pi/4, so the solutions are pi/4 and 5pi/4.
- Solve 2sin x - 1 = 0 on [0, 2pi). Answer: x = pi/6, 5pi/6 Reason: First isolate sine: 2sin x = 1, so sin x = 1/2. On [0, 2pi), that gives x = pi/6 and 5pi/6.

## Common Mistakes
- Writing only the reference angle as the answer.
- Forgetting a second quadrant or third quadrant solution with the same trig value.
- Including 2pi when the interval is [0, 2pi).
- Dividing by sin x or cos x and losing zero solutions.
- Using degree answers when the problem is in radians.
