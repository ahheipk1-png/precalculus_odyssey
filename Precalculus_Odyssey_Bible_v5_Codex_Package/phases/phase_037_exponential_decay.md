## Prerequisite Review
- A percent decrease of r becomes a multiplier of 1 - r.
- An exponential model uses repeated multiplication over equal intervals.
- A base between 0 and 1 creates decay when the initial value is positive.
- Half-life means multiplying by 1/2 for each half-life interval.
- Function notation tells which input value to substitute.

## Core Concepts
- An exponential decay model has the form A = a b^t with a > 0 and 0 < b < 1.
- The decay factor b is the amount kept each period.
- The percent decay rate is 1 - b, written as a percent.
- Half-life models can be written A = A0(1/2)^(t/h), where h is the half-life.
- Exponential decay approaches zero for positive initial values but does not reach zero in the basic model.
- Continuous decay uses A = P e^(-rt), where r is positive.

## Common Misconceptions
- Using 0.15 instead of 0.85 for a 15 percent decrease.
- Subtracting the same amount each period instead of multiplying by the same factor.
- Making the base negative because the situation is decreasing.
- Confusing half-life with subtracting half of the original amount each interval.
- Rounding the decay factor before solving when an exact fraction is available.

Master exponential decay by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A percent decrease of r becomes a multiplier of 1 - r.
- Can the player explain this prerequisite? An exponential model uses repeated multiplication over equal intervals.
- Can the player explain this prerequisite? A base between 0 and 1 creates decay when the initial value is positive.
- Can the player explain this prerequisite? Half-life means multiplying by 1/2 for each half-life interval.

## Core Concept
- An exponential decay model has the form A = a b^t with a > 0 and 0 < b < 1.
- The decay factor b is the amount kept each period.
- The percent decay rate is 1 - b, written as a percent.
- Half-life models can be written A = A0(1/2)^(t/h), where h is the half-life.
- Exponential decay approaches zero for positive initial values but does not reach zero in the basic model.
- Continuous decay uses A = P e^(-rt), where r is positive.

## Worked Example
- For A(t) = 120(0.8^t), what is the decay factor? Answer: 0.8 Reason: The base of the exponential expression is the per-period multiplier, so the decay factor is 0.8.
- What decay factor represents a 12 percent decrease each month? Answer: 0.88 Reason: A 12 percent decrease means 88 percent remains, so the multiplier is 1 - 0.12 = 0.88.
- If f(t) = 50(0.5^t), find f(3). Answer: 6.25 Reason: Substitute t = 3: f(3) = 50(0.5^3) = 50(0.125) = 6.25.
- A car is worth 18000 dollars and loses 10 percent of its value each year. Write V(t). Answer: V(t) = 18000(0.90^t) Reason: The initial value is 18000. Losing 10 percent means keeping 90 percent, so the decay factor is 0.90.

## Common Mistakes
- Using 0.15 instead of 0.85 for a 15 percent decrease.
- Subtracting the same amount each period instead of multiplying by the same factor.
- Making the base negative because the situation is decreasing.
- Confusing half-life with subtracting half of the original amount each interval.
- Rounding the decay factor before solving when an exact fraction is available.

## Independent Practice
- distinguish linear decrease from exponential decay: Which table is exponential decay: A has outputs 100, 90, 80, 70; B has outputs 100, 80, 64, 51.2? Expected answer: Table B.
- initial value from later value: A model has decay factor 0.5 and A(4) = 10. What is A(0)? Expected answer: 160.
- continuous decay evaluation: A medicine amount is M(t) = 80e^(-0.25t). How much remains after 4 hours, to the nearest tenth? Expected answer: 29.4.
- compare two decay models: Which is larger at t = 2: A(t) = 100(0.7^t) or B(t) = 80(0.8^t)? Expected answer: B(2) is larger.
- decay graph interpretation: A decay graph has y-intercept 300 and each step keeps 60 percent. Write the equation. Expected answer: y = 300(0.6^x).
- reverse engineer a decay factor: A value drops from 500 to 320 in two equal steps. What is the decay factor per step? Expected answer: 0.8.

## Mastery Check
- A player models a 30 percent decrease from 90 as 90(0.30^t). What should the model be? Mastery answer: A(t) = 90(0.70^t).
- For A(t) = 12(0.25^t), what value does A(t) approach as t becomes very large? Mastery answer: 0.
- A 72 gram sample has half-life 3 days. How much remains after 12 days? Mastery answer: 4.5 grams.
- A phone battery has 90 percent charge and loses 18 percent of its charge each hour. Estimate the charge after 3 hours to the nearest percent. Mastery answer: 50 percent.
