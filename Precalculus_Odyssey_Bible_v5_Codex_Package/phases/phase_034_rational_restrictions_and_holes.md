# Phase 034 - Rational restrictions and holes

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Rational restrictions and holes
- Subtopic: Identifying excluded values, holes, and vertical asymptotes from rational functions
- Prerequisites: rational expression simplification, factoring, domain restrictions, graph features
- Related phases: Phase 033 review; Phase 035 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of rational restrictions and holes tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving rational restrictions and holes questions.
3. Solve tasks involving find restrictions.
4. Solve tasks involving two restrictions.
5. Solve tasks involving hole from cancellation.
6. Solve tasks involving hole coordinate.
7. Solve tasks involving vertical asymptote.
8. Solve tasks involving hole and asymptote.
9. Solve tasks involving hole y-coordinate.
10. Solve tasks involving domain with hole and asymptote.

## Prerequisite Review
- A rational expression is a ratio of polynomials.
- Values that make the original denominator zero are excluded.
- A common factor can create a hole after cancellation.
- A non-cancelled denominator factor creates a vertical asymptote.
- Horizontal asymptotes are predicted from degrees and leading coefficients.

## Core Concepts
- Restrictions come from zeros of the original denominator.
- A cancelled denominator factor creates a hole.
- A non-cancelled denominator factor creates a vertical asymptote.
- The x-coordinate of a hole is the cancelled restriction.
- The y-coordinate of a hole is found from the simplified function.
- Domain excludes both holes and vertical asymptotes.

## Common Misconceptions
- Cancelling terms that are not common factors.
- Forgetting restrictions from the original denominator.
- Calling every excluded value an asymptote.
- Ignoring holes after simplifying.
- Using y-values instead of x-values for denominator restrictions.

# Part III - Tutorial Bible

## Learning Goal
Master rational restrictions and holes by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A rational expression is a ratio of polynomials.
- Can the player explain this prerequisite? Values that make the original denominator zero are excluded.
- Can the player explain this prerequisite? A common factor can create a hole after cancellation.
- Can the player explain this prerequisite? A non-cancelled denominator factor creates a vertical asymptote.

## Core Concept
- Restrictions come from zeros of the original denominator.
- A cancelled denominator factor creates a hole.
- A non-cancelled denominator factor creates a vertical asymptote.
- The x-coordinate of a hole is the cancelled restriction.
- The y-coordinate of a hole is found from the simplified function.
- Domain excludes both holes and vertical asymptotes.

## Worked Example
- Find restrictions for f(x)=1/(x-4). Answer: x != 4 Reason: The denominator is zero at x=4.
- Find restrictions for f(x)=1/((x-2)(x+3)). Answer: x != 2,-3 Reason: Both denominator factors can be zero.
- For f(x)=(x^2-9)/(x-3), identify the hole x-value. Answer: x=3 Reason: The factor x-3 cancels, so the excluded value becomes a hole.
- Find the hole of f(x)=(x^2-9)/(x-3). Answer: (3,6) Reason: Simplify to x+3, then evaluate at x=3 to get y=6.

## Common Mistakes
- Cancelling terms that are not common factors.
- Forgetting restrictions from the original denominator.
- Calling every excluded value an asymptote.
- Ignoring holes after simplifying.
- Using y-values instead of x-values for denominator restrictions.
