# Phase 045 - Exact trigonometric values

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Exact trigonometric values
- Subtopic: Special angles, quadrants, reciprocal functions, and exact unit-circle evaluation
- Prerequisites: Degree and radian measure, reference angles, the unit circle, special right triangles, and quadrant signs
- Related phases: Phase 044 review; Phase 046 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of exact trigonometric values tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving exact trigonometric values questions.
3. Solve tasks involving sine of a first-quadrant special angle.
4. Solve tasks involving cosine with a quadrant ii sign.
5. Solve tasks involving tangent with a quadrant iii sign.
6. Solve tasks involving cosecant as a reciprocal.
7. Solve tasks involving secant as a reciprocal.
8. Solve tasks involving cotangent from tangent.
9. Solve tasks involving degree angle exact sine.
10. Solve tasks involving even behavior of cosine.

## Prerequisite Review
- Convert between degrees and radians for common angles such as 30 degrees, 45 degrees, 60 degrees, and 180 degrees.
- Use 30-60-90 and 45-45-90 triangles to recall sine, cosine, and tangent values.
- Locate an angle on the unit circle and identify its reference angle.
- Apply quadrant signs for sine, cosine, and tangent before writing the final value.

## Core Concepts
- Exact trigonometric values come from unit-circle coordinates and special right triangles.
- The cosine of an angle is the x-coordinate and the sine is the y-coordinate on the unit circle.
- Tangent is sine divided by cosine, so its sign depends on both coordinates.
- Reciprocal functions use csc x = 1/sin x, sec x = 1/cos x, and cot x = 1/tan x when defined.
- Coterminal angles have the same exact trigonometric values.

## Common Misconceptions
- Using the reference angle value but forgetting the quadrant sign.
- Treating secant, cosecant, and cotangent as inverse angle functions instead of reciprocals.
- Giving decimal approximations when an exact value is requested.
- Confusing the sine and cosine coordinates for 30 degree and 60 degree angles.
- Forgetting that tangent is undefined when cosine is zero.

# Part III - Tutorial Bible

## Core Concept
- Exact trigonometric values come from unit-circle coordinates and special right triangles.
- The cosine of an angle is the x-coordinate and the sine is the y-coordinate on the unit circle.
- Tangent is sine divided by cosine, so its sign depends on both coordinates.
- Reciprocal functions use csc x = 1/sin x, sec x = 1/cos x, and cot x = 1/tan x when defined.
- Coterminal angles have the same exact trigonometric values.

## Worked Example
- Find the exact value of sin(pi/6). Answer: 1/2 Reason: The angle pi/6 is 30 degrees. On the unit circle its y-coordinate is 1/2, so sin(pi/6) = 1/2.
- Find the exact value of cos(2pi/3). Answer: -1/2 Reason: The reference angle for 2pi/3 is pi/3. Cosine is negative in quadrant II, so cos(2pi/3) = -cos(pi/3) = -1/2.
- Find the exact value of tan(5pi/4). Answer: 1 Reason: The reference angle is pi/4. In quadrant III, sine and cosine are both negative, so tangent is positive. Thus tan(5pi/4) = 1.
- Find the exact value of csc(7pi/6). Answer: -2 Reason: Since 7pi/6 has reference angle pi/6 in quadrant III, sin(7pi/6) = -1/2. Therefore csc(7pi/6) = 1/(-1/2) = -2.

## Common Mistakes
- Using the reference angle value but forgetting the quadrant sign.
- Treating secant, cosecant, and cotangent as inverse angle functions instead of reciprocals.
- Giving decimal approximations when an exact value is requested.
- Confusing the sine and cosine coordinates for 30 degree and 60 degree angles.
- Forgetting that tangent is undefined when cosine is zero.
