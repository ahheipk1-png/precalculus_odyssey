# Phase 043 - Reference angles

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Reference angles
- Subtopic: Reference angles in degrees and radians across all quadrants
- Prerequisites: Degree and radian measure, coordinate planes, quadrants, and coterminal angles
- Related phases: Phase 042 review; Phase 044 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of reference angles tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving reference angles questions.
3. Solve tasks involving reference angle in quadrant i.
4. Solve tasks involving reference angle in quadrant ii.
5. Solve tasks involving reference angle in quadrant iii.
6. Solve tasks involving reference angle in quadrant iv.
7. Solve tasks involving negative angle reference.
8. Solve tasks involving angle above 360 degrees.
9. Solve tasks involving quadrantal angle.
10. Solve tasks involving radian quadrant i.

## Prerequisite Review
- A reference angle is always positive and acute, except for quadrantal angles where it is 0.
- Quadrant I angles have reference angle equal to the angle.
- Quadrant II reference angle is 180 degrees minus the angle.
- Quadrant III reference angle is the angle minus 180 degrees.
- Quadrant IV reference angle is 360 degrees minus the angle.

## Core Concepts
- Reference angles measure the acute angle from the terminal side to the x-axis.
- For radian angles, use pi, 2pi, and their fractions the same way as 180 degrees and 360 degrees.
- Negative or large angles should be made coterminal in the standard range before finding the reference angle.
- Reference angles help transfer exact trig values across quadrants.
- The reference angle is positive even when the original angle is negative.
- Quadrantal angles land on an axis and have reference angle 0.

## Common Misconceptions
- Returning the original obtuse angle as the reference angle.
- Keeping a negative reference angle for a negative rotation.
- Using 90 degrees as the reference line instead of the x-axis.
- Forgetting to reduce angles larger than 360 degrees.
- Confusing the reference angle with the coterminal angle.

# Part III - Tutorial Bible

## Learning Goal
Master reference angles by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A reference angle is always positive and acute, except for quadrantal angles where it is 0.
- Can the player explain this prerequisite? Quadrant I angles have reference angle equal to the angle.
- Can the player explain this prerequisite? Quadrant II reference angle is 180 degrees minus the angle.
- Can the player explain this prerequisite? Quadrant III reference angle is the angle minus 180 degrees.

## Core Concept
- Reference angles measure the acute angle from the terminal side to the x-axis.
- For radian angles, use pi, 2pi, and their fractions the same way as 180 degrees and 360 degrees.
- Negative or large angles should be made coterminal in the standard range before finding the reference angle.
- Reference angles help transfer exact trig values across quadrants.
- The reference angle is positive even when the original angle is negative.
- Quadrantal angles land on an axis and have reference angle 0.

## Worked Example
- Find the reference angle for 35 degrees. Answer: 35 degrees Reason: The angle is already in Quadrant I, so its reference angle is 35 degrees.
- Find the reference angle for 140 degrees. Answer: 40 degrees Reason: Quadrant II reference angle is 180 degrees minus the angle: 180 - 140 = 40 degrees.
- Find the reference angle for 225 degrees. Answer: 45 degrees Reason: Quadrant III reference angle is angle minus 180 degrees: 225 - 180 = 45 degrees.
- Find the reference angle for 315 degrees. Answer: 45 degrees Reason: Quadrant IV reference angle is 360 degrees minus the angle: 360 - 315 = 45 degrees.

## Common Mistakes
- Returning the original obtuse angle as the reference angle.
- Keeping a negative reference angle for a negative rotation.
- Using 90 degrees as the reference line instead of the x-axis.
- Forgetting to reduce angles larger than 360 degrees.
- Confusing the reference angle with the coterminal angle.
