# Phase 022 - Quadratic factoring

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Quadratic factoring
- Subtopic: Factoring quadratic expressions and solving quadratic equations by factoring
- Prerequisites: distributive property, integer factors, zero product property, simplifying expressions
- Related phases: Phase 021 review; Phase 023 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of quadratic factoring tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving quadratic factoring questions.
3. Solve tasks involving factor x^2+bx+c positive.
4. Solve tasks involving factor with negative middle.
5. Solve tasks involving factor with negative constant.
6. Solve tasks involving perfect square trinomial.
7. Solve tasks involving difference of squares.
8. Solve tasks involving greatest common factor first.
9. Solve tasks involving gcf then trinomial.
10. Solve tasks involving leading coefficient greater than 1.

## Prerequisite Review
- A quadratic in standard form has terms ax^2+bx+c.
- Factoring rewrites a sum as a product.
- The zero product property says if AB=0, then A=0 or B=0.
- A greatest common factor should be removed before trinomial factoring.
- Factoring can reveal x-intercepts of a quadratic graph.

## Core Concepts
- For x^2+bx+c, find two numbers that multiply to c and add to b.
- For x^2-bx+c, both factor signs may be negative.
- If c is negative, the factor signs are opposite.
- For ax^2+bx+c, use grouping or another reliable factoring method.
- After factoring an equation equal to zero, set each factor equal to zero.
- Not every quadratic factors over integers.

## Common Misconceptions
- Factoring only the first and last terms.
- Using numbers that add to c instead of multiply to c.
- Solving factors before the equation equals zero.
- Dropping a negative sign during grouping.
- Assuming every quadratic has integer factors.

# Part III - Tutorial Bible

## Learning Goal
Master quadratic factoring by choosing the right representation, completing the computation, and interpreting the result.

## Why It Matters
This topic appears in later modeling, graphing, and boss challenges because it connects symbolic work with decisions about structure, restrictions, and meaning.

## Prerequisite Check
- Can the player explain this prerequisite? A quadratic in standard form has terms ax^2+bx+c.
- Can the player explain this prerequisite? Factoring rewrites a sum as a product.
- Can the player explain this prerequisite? The zero product property says if AB=0, then A=0 or B=0.
- Can the player explain this prerequisite? A greatest common factor should be removed before trinomial factoring.

## Core Concept
- For x^2+bx+c, find two numbers that multiply to c and add to b.
- For x^2-bx+c, both factor signs may be negative.
- If c is negative, the factor signs are opposite.
- For ax^2+bx+c, use grouping or another reliable factoring method.
- After factoring an equation equal to zero, set each factor equal to zero.
- Not every quadratic factors over integers.

## Worked Example
- Factor x^2+7x+12. Answer: (x+3)(x+4) Reason: The numbers 3 and 4 multiply to 12 and add to 7.
- Factor x^2-9x+20. Answer: (x-4)(x-5) Reason: The numbers -4 and -5 multiply to 20 and add to -9.
- Factor x^2+x-12. Answer: (x+4)(x-3) Reason: The numbers 4 and -3 multiply to -12 and add to 1.
- Factor x^2+10x+25. Answer: (x+5)^2 Reason: Both factors are x+5 because 5 and 5 multiply to 25 and add to 10.

## Common Mistakes
- Factoring only the first and last terms.
- Using numbers that add to c instead of multiply to c.
- Solving factors before the equation equals zero.
- Dropping a negative sign during grouping.
- Assuming every quadratic has integer factors.
