# Phase 048 - Phase and vertical shifts

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Phase and vertical shifts
- Subtopic: Horizontal and vertical translations of trigonometric graphs
- Prerequisites: Amplitude and period, function transformations, trig graph key points, and solving simple linear equations
- Related phases: Phase 047 review; Phase 049 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of phase and vertical shifts tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving phase and vertical shifts questions.
3. Solve tasks involving vertical shift and midline.
4. Solve tasks involving right phase shift.
5. Solve tasks involving left phase shift.
6. Solve tasks involving midline with amplitude.
7. Solve tasks involving full feature reading for shifted cosine.
8. Solve tasks involving reflection with shifts.
9. Solve tasks involving interpreting first midline crossing.
10. Solve tasks involving range with vertical shift.

## Prerequisite Review
- Identify amplitude and period from equations of the form y = A sin(Bx) and y = A cos(Bx).
- Use horizontal shift language: x - C means right C and x + C means left C.
- Find a midline by averaging maximum and minimum values.
- Factor the inside expression before reading a phase shift.

## Core Concepts
- In y = A sin(B(x - C)) + D, the phase shift is right C and the vertical shift is D.
- The midline of y = A sin(B(x - C)) + D or y = A cos(B(x - C)) + D is y = D.
- The range of a shifted sine or cosine graph is [D - |A|, D + |A|].
- When the inside is Bx - K, factor B first to get B(x - K/B).
- A phase shift changes where the cycle begins but does not change amplitude.

## Common Misconceptions
- Reading x - C as a shift left instead of right.
- Using K instead of K/B as the shift in Bx - K.
- Treating the vertical shift as the amplitude.
- Forgetting that reflection changes orientation but not midline.
- Using maximum or minimum as the midline.

# Part III - Tutorial Bible

## Learning Goal

## Why It Matters

## Prerequisite Check

- Can the player explain this prerequisite? Use horizontal shift language: x - C means right C and x + C means left C.
- Can the player explain this prerequisite? Find a midline by averaging maximum and minimum values.
- Can the player explain this prerequisite? Factor the inside expression before reading a phase shift.

## Core Concept
- In y = A sin(B(x - C)) + D, the phase shift is right C and the vertical shift is D.
- The midline of y = A sin(B(x - C)) + D or y = A cos(B(x - C)) + D is y = D.
- The range of a shifted sine or cosine graph is [D - |A|, D + |A|].
- When the inside is Bx - K, factor B first to get B(x - K/B).
- A phase shift changes where the cycle begins but does not change amplitude.

## Worked Example
- For y = sin x + 2, identify the vertical shift and midline. Answer: Vertical shift up 2; midline y = 2 Reason: Adding 2 outside the sine function moves every y-value up by 2. The midline moves from y = 0 to y = 2.
- For y = sin(x - pi/3), identify the phase shift. Answer: Right pi/3 Reason: The expression x - pi/3 means the input must be pi/3 larger to match the basic sine graph, so the graph shifts right pi/3.
- For y = cos(x + pi/4), identify the phase shift. Answer: Left pi/4 Reason: The expression x + pi/4 is the same as x - (-pi/4). That represents a shift left pi/4.
- For y = 3sin x - 1, identify the midline. Answer: y = -1 Reason: The -1 outside the sine function shifts the entire graph down 1. The midline is y = -1.

## Common Mistakes
- Reading x - C as a shift left instead of right.
- Using K instead of K/B as the shift in Bx - K.
- Treating the vertical shift as the amplitude.
- Forgetting that reflection changes orientation but not midline.
- Using maximum or minimum as the midline.
