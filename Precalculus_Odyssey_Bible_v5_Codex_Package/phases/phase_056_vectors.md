# Phase 056 - Vectors

## Phase Metadata
- Course: Precalculus Odyssey Bible v5
- Topic: Vectors
- Subtopic: Vector components, magnitude, dot products, projections, and applications
- Prerequisites: coordinate plane, right triangle trigonometry, distance formula, basic algebra
- Related phases: Phase 055 review; Phase 057 follow-up; mixed review and final boss integration
- Estimated phase size: 20 template families, 20 core examples, 120 progressive hints, 1 tutorial sequence, 1 Socratic dialogue system

## Learning Objectives
By the end of this phase, the player can:

1. Recognize the structure of vectors tasks before choosing a method.
2. Use correct notation, restrictions, and units while solving vectors questions.
3. Solve tasks involving building a vector from two points.
4. Solve tasks involving finding magnitude.
5. Solve tasks involving creating a unit vector.
6. Solve tasks involving adding vectors.
7. Solve tasks involving scalar multiplication.
8. Solve tasks involving combining displacement vectors.
9. Solve tasks involving computing a dot product.
10. Solve tasks involving testing perpendicular vectors.

## Prerequisite Review
- Subtract coordinates in the order terminal minus initial to form a displacement vector.
- Use the Pythagorean theorem to find lengths from horizontal and vertical components.
- Use sine and cosine to convert between magnitude-direction form and components.
- Remember that scalar multiplication changes length and may reverse direction.
- Interpret units carefully when vectors model velocity, force, or displacement.

## Core Concepts
- A vector represents magnitude and direction, not a fixed location.
- Component form lets vectors be added, subtracted, and scaled coordinate by coordinate.
- Magnitude measures vector length and comes from the distance formula.
- The dot product measures alignment and can detect perpendicular vectors.
- Projection gives the part of one vector that points in the direction of another.

## Common Misconceptions
- Subtracting coordinates in the wrong order when building a vector.
- Adding magnitudes instead of adding components.
- Treating a dot product as another vector instead of a scalar.
- Forgetting to divide by magnitude when creating a unit vector.
- Using the wrong angle reference when converting direction to components.

## Why It Matters

## Prerequisite Check

- Can the player explain this prerequisite? Use the Pythagorean theorem to find lengths from horizontal and vertical components.
- Can the player explain this prerequisite? Use sine and cosine to convert between magnitude-direction form and components.
- Can the player explain this prerequisite? Remember that scalar multiplication changes length and may reverse direction.

## Core Concept
- A vector represents magnitude and direction, not a fixed location.
- Component form lets vectors be added, subtracted, and scaled coordinate by coordinate.
- Magnitude measures vector length and comes from the distance formula.
- The dot product measures alignment and can detect perpendicular vectors.
- Projection gives the part of one vector that points in the direction of another.

## Worked Example
- Find the vector from A(2, -3) to B(7, 5). Answer: <5, 8>. Reason: Subtract initial coordinates from terminal coordinates: <7 - 2, 5 - (-3)> = <5, 8>.
- Find the magnitude of <6, -8>. Answer: 10. Reason: The magnitude is sqrt(6^2 + (-8)^2) = sqrt(36 + 64) = sqrt(100) = 10.
- Find a unit vector in the direction of <3, 4>. Answer: <3/5, 4/5>. Reason: The magnitude of <3, 4> is 5. Divide each component by 5 to get the unit vector <3/5, 4/5>.
- Compute <2, -1> + <-5, 4>. Answer: <-3, 3>. Reason: Add corresponding components: <2 + (-5), -1 + 4> = <-3, 3>.

## Common Mistakes
- Subtracting coordinates in the wrong order when building a vector.
- Adding magnitudes instead of adding components.
- Treating a dot product as another vector instead of a scalar.
- Forgetting to divide by magnitude when creating a unit vector.
- Using the wrong angle reference when converting direction to components.
